# YouBudget: Budgeting Web Application

## Overview

YouBudget is a budgeting web application for tracking income and expenses. Key features include income and expense logging, transaction visualization via Chart.js, and automated financial data processing.

**[Watch the YouBudget Demo](https://drive.google.com/file/d/1_kqwVw7wXfkSyyDnvHQCHVFXmjjXPdLl/view?usp=sharing)**

## Preview

![YouBudget Homepage](images/project/project-homepage.png)

## Key Features

- **Transaction Logging**: Income and expense tracking with dynamic row management and table clearing.
- **Data Visualization**: Interactive monthly transaction visualization leveraging Chart.js.
- **Input Validation**: Client-side validation logic to ensure data integrity and prevent empty submissions.
- **API Integration**: REST API implementation for efficient communication between the frontend and Java backend.
- **Financial State Management**: Backend processing in Java to calculate budget totals and manage transaction data.

## Tech Stack

Java, JavaScript, Chart.js, HTML, CSS, REST API
